[$20 bounty on make.fun](https://make.fun/bounty/post-x-the-agent-builds-a-game-from-20261122-1709).

## The one prompt

> Build a tiny browser game where a hungry fox catches falling apples —
> arrow keys to move, score points, 3 lives.

## The game

Open `fox-apple-catch.html` in any browser and press **Start game**.
Move the fox with the left/right arrow keys (or drag on touch screens),
catch the falling apples for 10 points each, and don't let them hit the
ground — you have 3 lives. Apples fall faster as your score grows.
